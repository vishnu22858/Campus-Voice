# Campus Voice

**Your campus. Your voice.**

Campus Voice is a college announcement website designed for Dr. Ambedkar Institute of Technology, Bengaluru. It provides a simple interface for browsing campus announcements related to academics, events, and placements.

## Features

- Browse announcements by category.
- Search announcements by their content.
- Sort announcements alphabetically or by star count.
- Star and unstar announcements.
- Publish new announcements through a form.
- Responsive layout for desktop and mobile screens.

## Technologies Used

- HTML5
- Tailwind CSS (CDN)
- JavaScript
- Browser localStorage for star information


## Running Locally

1. Download or clone the project repository.
2. Open the project folder.
3. Open `index.html` in a web browser.

An internet connection is required to load Tailwind CSS from its CDN.

## Current Limitations

- Announcements created through the form are stored only in the current page and disappear when the page is refreshed.
- Star counts and star choices are stored in the current browser and are not shared between users or devices.
- The project does not currently have a backend or database.
